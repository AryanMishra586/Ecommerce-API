# Ecommerce-API

A modular, production-ready E-commerce REST API built with **Node.js**, **Express**, and **MongoDB**. The API provides secure authentication, structured routing, and clean architecture patterns suitable for scalable backend development.

---

## Features

- User authentication and authorization using JSON Web Tokens (JWT)
- RESTful CRUD operations for Users, Products, and Orders
- Middleware driven architecture (authentication, validation, error handling)
- MongoDB database integration
- API documentation using Swagger (OpenAPI)
- Clean and modular folder structure for scalability

---

## Technology Stack

- **Runtime:** Node.js  
- **Framework:** Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT  
- **Documentation:** Swagger
